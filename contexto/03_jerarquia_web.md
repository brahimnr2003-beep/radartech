# Jerárquica de la web

La plataforma seguirá una estructura jerárquica.

Nivel 1

España

Mapa de comunidades autónomas (más Ceuta y Melilla).

Nivel 2

Comunidad Autónoma

Por ejemplo:

/eventos/andalucia

Aquí se mostrarán todos los eventos tecnológicos de Andalucía.

Posteriormente podría aparecer un segundo mapa:

Andalucía

- Málaga
- Granada
- Sevilla
- Cádiz
- Córdoba
- Jaén
- Huelva
- Almería

Nivel 3

Provincia

Por ejemplo:

/eventos/andalucia/malaga

Por el momento se desarrollará la web hasta el nivel 2, comunidades.

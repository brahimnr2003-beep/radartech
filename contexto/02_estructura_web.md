# Estructura web

Hero

- Una presentación breve del proyecto:
'Descubre los eventos tecnológicos más relevantes de España.'
Con una explicación corta y un CTA para explorar.

Debajo del hero aparecerá rápidamente el elemento principal:

🗺️ Mapa interactivo de España

El mapa mostrará inicialmente las 17 comunidades autónomas.

Cada comunidad será una zona interactiva.

Cuando el usuario coloque el cursor sobre una comunidad:

- se resaltará visualmente;
- aparecerá el nombre;
- podrá mostrarse el número de eventos disponibles;
- opcionalmente podrán mostrarse algunos datos resumidos.

Por ejemplo:

Andalucía
42 eventos próximos

Al hacer clic:

España → Andalucía

el usuario será redirigido a una página específica de la comunidad.

En la pagina de la comunidad podra ver a detalle cada evento.

Los colores de la web serán negros y naranjas con resaltado en neón, sombras,....
